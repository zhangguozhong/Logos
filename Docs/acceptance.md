# 接入验收要求

- **身份与回捞**。用匿名、登录、切号、登出和跨切号异步请求验证现场归属。已授权样本应能找回，跨用户误归属和越权导出均应为 0 条。按文件检查显式上报的关键事件、告警及异常。
- **留存与恢复**。验证跨日、应用重启、目录满、密钥不可用和网络恢复。检查各类日志的可见范围和拒绝原因。事先约定代表性会话的覆盖时长及故障前要保留的事件；用实际可读记录核对。
- **性能**。保持同一设备、负载和预算，分别记录启用和关闭 SDK 的帧 P99、后台线程 CPU 和文件留存率。桌面混合负载的每档五窗 CPU 波动门槛为 15%。当前三档均未通过。[最近一次公开结果](benchmarks/unity-mixed-load.md)
- **平台限制**。Android 和 iOS 需在目标宿主验证暂停、恢复、安全卸载及再次挂接，并另外测量持续运行时的温升、能耗和业务帧耗时。
